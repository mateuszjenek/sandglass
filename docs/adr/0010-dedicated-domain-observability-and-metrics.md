# Dedicated Domain Observability and Metrics

Sandglass exposes domain-specific Prometheus metrics (`sandglass_ephemeral_deployments_active`, `sandglass_ephemeral_deployments_created_total`, `sandglass_ephemeral_deployments_purged_total`, and `sandglass_ttl_duration_seconds`) to give platform engineers direct visibility into ephemeral preview adoption, active cluster resource footprint, and automated TTL cleanup efficiency.
