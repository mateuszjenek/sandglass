## Reporting a Vulnerability

We take the security of **Sandglass** seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the project maintainers directly.
3. Include detailed steps to reproduce the issue, along with affected versions and any potential mitigations.

You will receive an acknowledgment within 48 hours, followed by regular updates until a fix is published.
